# AI agents: prompting and context

> *AI-reviewed content: may change at any time and should not be fully trusted. See the [disclaimer](../../start/disclaimer.md).*

- **Keep the active rule file short.** Every rule names the mistake it prevents, and facts and history live in searchable records instead.
- **Use one causal question per task,** with an explicit stop condition and a resume step written to disk.
- **Hand off through files:** the task card, the evidence and a checkpoint, never "as discussed".
- **Run builder and reviewer one at a time,** each reading the other's output fresh.
- **Ask the user only for decisions** (adaptations, workarounds, publication); the agent does the archaeology itself.
