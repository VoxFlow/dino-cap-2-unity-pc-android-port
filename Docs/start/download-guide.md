# Download guide

> *AI-reviewed content: may change at any time and should not be fully trusted. See the [disclaimer](disclaimer.md).*

Get the game from the **Releases** section of this GitHub page. The green *Code* button downloads the source code, not the game.

## Windows (64-bit)

1. Download the Windows zip and extract it anywhere. Keep the folder together: `Dino Cap 2.exe` needs `Dino Cap 2_Data` next to it.
2. Run `Dino Cap 2.exe`. The file is unsigned, so Windows SmartScreen may warn; choose *More info → Run anyway* only if you trust the source.
3. The first launch opens a 4:3 window sized to your screen. <kbd>F11</kbd> or <kbd>Alt</kbd>+<kbd>Enter</kbd> toggles fullscreen. The window size and the fullscreen choice are remembered.

Saves and settings are stored under your user's `AppData\LocalLow\Pilot\Dino Cap 2`.

## Android

1. Download `Dino Cap 2.apk` on the phone.
2. Allow installing from your browser or file manager when Android asks, then open the APK.
3. One APK covers both 32-bit (ARMv7) and 64-bit (ARM64) phones. Some budget phones run a 32-bit Android even on a 64-bit chip; that is why both are included.

The Android package id is a neutral project id, `com.pilot.dc2port`, not the original game's.

See also [controls for PC](controls-pc.md), [controls for phones](controls-mobile.md) and [troubleshooting](troubleshooting.md).
